# Uploaded ticket files

Every `.csv` in this folder is a dataset the app can analyse.

* Files added on the **Datasets** page are saved here.
* **Delete a file here and the app stops using it.** No restart needed.
* Copy a CSV in (same columns as `../rideops_support_tickets.csv`) and it shows up on the Datasets page.
* If two files hold the same ticket ID, the newer file wins.
* The original data (`../rideops_support_tickets.csv`) is not in this folder.
